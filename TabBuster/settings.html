      TABBUSTER · HELP

      Fewer interruptions.

      Start with an unwanted tab

      Open the TabBuster toolbar menu and click Add this tab/site to add the current page. Use the arrow for Add entire hostname.

      Leave Close current tab on to dismiss it immediately and count a successful defense. Turn it off to save the rule while keeping that tab open at its current URL for this session.

      Tip: pin TabBuster in your browser's Extensions menu so it is always within reach.

      One page or the whole site?

      Only this page matches its hostname, port and exact path. Query strings and #fragments are ignored; HTTP and HTTPS both match. A trailing slash makes a different path.

      Every page on this hostname closes all paths on that hostname. The www version and other subdomains need separate entries. Wildcards are not supported.

      To add a page that disappears too quickly, paste its URL into Settings. Start with a page rule when you want to keep the rest of a site available.

      Pause, remove or revisit a page

      Turn on Pause automatic closing in the toolbar popup, or turn off Automatically close matching tabs in Settings. Both controls update the same preference. Resume by turning Pause off; existing matching tabs may then close. Your list stays saved. Remove a rule to stop matching it permanently.

      Listed pages also close when opened deliberately. Pause before revisiting one. The toolbar's explicit Close current tab choice still works while automatic closing is paused.

      Rules apply immediately to open tabs. Closing a window's last tab may close that window. The keep-open exception ends when its URL changes or the browser/extension session restarts.

      Quiet notifications and website access

      Notify me when a tab closes controls all closure notices. Windows notifications work without website access.

      For a five-second, bottom-right webpage notice, enable In-browser notifications in Settings and approve the browser's request for HTTP/HTTPS website access. Turning it off revokes that optional access. Declining does not affect tab closing.

      The notice shows the closed hostname. Rapid closures share one notice; click × to dismiss it early. Protected pages, including browser settings and extension stores, use a desktop notification instead. Windows Do Not Disturb can hide that fallback.

      Counts and recently closed tabs

      Total counts successful TabBuster closures and survives restarts. This session resets when the browser restarts or the extension is reloaded, updated or disabled. Background inactivity does not reset it.

      Adding a rule without closing a tab does not count. Failed closures and duplicate browser events do not earn extra defenses.

      Settings shows the last 50 closures. Clear recent history removes that list without resetting the counters.

      Milestones and celebrations

      Celebrate at 1, 50, 100, 250, 500, then every 1,000 successful defenses. The number splashes into place with a spark burst; confetti continues while the milestone is visible.

      Keep busting dismisses the milestone. If the browser cannot open the popup automatically, a star badge marks the celebration for your next visit. Only the latest pending milestone is shown.

      Turn off Celebrate defense milestones to suppress them. Your device's reduced-motion setting replaces the effects with a static card.

      Something still getting through?

      Check that automatic closing is on and the rule matches the actual hostname and path. Watch for www, other subdomains, and trailing slashes. A tab added with immediate closing off is intentionally kept open.

      After an update, reload TabBuster from the browser's Extensions page. If webpage notices are missing, check the notification switches and approved website access. Read the last notification result beneath In-browser notifications. In Opera, search-results pages may also require Allow access to search page results in the extension details.

      A tab may briefly appear, take focus or begin loading before TabBuster closes it. This is a tab closer, not a network blocker or malware scanner.

      Privacy and permissions

      Rules, preferences, counters and recent closures stay on this device. Saved closure addresses omit query strings, fragments, credentials and titles. Private-tab closures are labelled Private tab.

      Tab access identifies matching URLs. Optional website access displays notices without reading page contents. There are no analytics, remote code or background network requests. Website and Ko-fi links open only when clicked.

      Removing the extension clears its saved data. Keep the same installation folder when updating to retain your settings.
